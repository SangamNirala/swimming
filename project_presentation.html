📋 Project Overview

Mission: Build a deep learning-based system to automatically detect drowning behavior in swimming pool videos through real-time analysis.

🎯

Objective

Detect swimmers and classify behavior (swimming vs drowning) using computer vision and deep learning.

🏗️

Architecture

Two-stage detection system: YOLOv8 for person detection + CNN-LSTM for action classification.

💻

Technology Stack

FastAPI (Backend), React (Frontend), MongoDB (Database), PyTorch, YOLOv8, OpenCV.

🚀

Deployment

CPU-only inference (no GPU required), optimized for local deployment on user's PC.

⚙️ Data Preprocessing Pipeline

Comprehensive preprocessing suite with 6 production-ready modules:

1️⃣ Frame Extractor

frame_extractor.py

  • Extract frames from videos at 5-10 FPS
  • Supports: mp4, avi, mov, mkv
  • Time range selection
  • Batch processing

2️⃣ Image Resizer

image_resizer.py

  • Resize to 640×640 (YOLO standard)
  • Letterboxing with aspect ratio preservation
  • Gray padding RGB(114,114,114)
  • Bbox coordinate transformation

3️⃣ Image Normalizer

normalizer.py

  • Standard: [0-255] → [0-1]

🔧 Technical Implementation Details

Annotation Processing Pipeline

# YOLOv8s Annotation Pipeline 1. Load YOLOv8s pretrained model (yolov8s.pt) 2. Configure detection parameters: - Confidence threshold: 0.15 - IoU threshold: 0.45 - Input size: 640×640 3. Batch process images (32 per batch) 4. Generate YOLO format annotations 5. Validate annotation format 6. Organize in GitHub-friendly batches (≤1000 files) Processing Speed: ~10-15 images/second on CPU Total Time: ~10-15 minutes for 9,342 images

Visualization Rendering

# OpenCV-based Visualization def visualize_annotation(image, annotation): # Read YOLO annotation class_id, cx, cy, w, h = parse_annotation() # Convert normalized to pixel coordinates x1, y1, x2, y2 = yolo_to_pixels(cx, cy, w, h) # Draw bounding box color = GREEN if class_id == 0 else RED cv2.rectangle(image, (x1,y1), (x2,y2), color, 3) # Draw label with background label = f"{person_id}: {class_name}" cv2.rectangle(image, label_bg_coords, color, -1) cv2.putText(image, label, position, FONT, WHITE) # Draw center point cv2.circle(image, (cx_pixel, cy_pixel), 5, WHITE, -1) # Save with 92% JPEG quality cv2.imwrite(output_path, image, [JPEG_QUALITY, 92]) Result: 116.7 images/second, 100% success rate
